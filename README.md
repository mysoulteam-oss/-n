# newo.ai — выгрузка разговоров

Скрипт `newo_export.py` подключается к [newo.ai](https://newo.ai) по API-ключу и выгружает разговоры (звонки и чаты) агента за указанный день.

## Как пользоваться

1. Скопируйте `.env.example` в `.env` и вставьте свой API-ключ (в платформе: **Account → API Keys**). Файл `.env` не коммитится.
2. Запустите выгрузку (нужен только Python 3, без зависимостей):

```bash
export NEWO_API_KEY=...          # или: export $(cat .env)
python3 newo_export.py            # вчерашний день
python3 newo_export.py 2026-07-01 # конкретная дата
```

Опции: `--tz-offset 3` — часовой пояс (по умолчанию Киев, UTC+3), `--out exports` — папка вывода.

## Что получается

В папке `exports/` (не коммитится — там персональные данные клиентов):

- `conversations_<дата>.md` — читаемые транскрипты «Клиент ↔ Агент» с итоговым резюме каждой сессии;
- `conversations_<дата>.json` — те же диалоги в структурированном виде;
- `acts_raw_<дата>.json` — полный сырой лог событий платформы за день.

## Как это работает

1. `POST /api/v1/auth/api-key/token` (заголовок `x-api-key`) — обмен ключа на JWT-токен (живёт 15 минут).
2. `GET /api/v1/conversations/acts` — постраничная выгрузка лога событий (новые сверху) до границы нужного дня.
3. Из лога отбираются реплики диалога (`user_message`, `user_message_transcription_finished`, `agent_message` к пользователю), дубли от рассылки события нескольким агентам убираются, реплики группируются по клиенту и паузам > 15 минут в сессии.

Базовый URL API: `https://app.newo.ai`.
