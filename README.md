# -n

Python-проект для подключения к API сервиса «Нево аи».

## Быстрый старт

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Настроить ключ и endpoint
cp .env.example .env
# затем открой .env и впиши API_KEY и API_BASE_URL

# 3. Запустить
python main.py
```

## Структура

| Файл              | Назначение                                           |
| ----------------- | ---------------------------------------------------- |
| `config.py`       | Загрузка настроек из `.env`                           |
| `client.py`       | Клиент API (здесь правится формат запроса под сервис) |
| `main.py`         | Точка входа — простой чат в терминале                 |
| `.env.example`    | Шаблон настроек (скопировать в `.env`)                |

## Безопасность

- Файл `.env` с ключом **в git не попадает** (см. `.gitignore`).
- Ключ читается только из переменной окружения `API_KEY`.
