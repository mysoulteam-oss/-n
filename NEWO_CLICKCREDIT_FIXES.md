# ClickCredit (Newo.ai) — готовые к применению правки

> Применяется в **builder.newo.ai** под вашим логином (агент «Franch»).
> Через партнёрский API-ключ это недоступно: ключ не обменивается на токен,
> а промпты/шаблоны/атрибуты/персона правятся только в билдере.
> Ниже — точные тексты для вставки + где именно их разместить.

---

## 1. SMS — всегда фиксированный текст

**Где:** билдер → Attributes → `project_attributes_setting_sms_send_information_allowed_content`
(либо детерминированный скилл отправки — см. §3, вариант A).

**Тело сообщения (ровно этот текст, без плейсхолдеров и перевода):**

```
Будь ласка, використайте це посилання для завершення реєстрації: https://clickcredit.ua/
```

Требование «завжди цей текст» несовместимо с генерацией/переводом внутри
`SendSMSInformation` (перевод может исказить текст, анти-дубль — заблокировать
повтор). Поэтому надёжнее слать **литерал** детерминированно (§3, вариант A).

---

## 2. Голосовой агент переходит на английский «при отправке»

Cause-agnostic фикс — закрывает все вероятные причины сразу:

1. **Не произносить URL/латиницу вслух.** В скилле отправки голосом говорить
   только украинскую фразу, без ссылки:
   ```
   Я надіслала вам посилання для завершення реєстрації у повідомленні.
   ```
   (Ссылка идёт только в SMS, не в речь. Часто «английский при отправке» — это
   просто зачитанный вслух латинский URL.)

2. **SMS — детерминированный литерал** (см. §1 и §3-A), без перевода/генерации.

3. **Языковой замок на скилле отправки** — добавить в начало его промпта:
   ```
   Формуй будь-яке повідомлення та мовлення виключно українською мовою,
   незалежно від мови попереднього контексту, шаблону чи системних даних.
   Ніколи не переходь на іншу мову. URL вголос не зачитуй.
   ```

**Различающий тест:** один звонок → записать аудио и пришедшую SMS раздельно →
определить, где английский: (a) в тексте SMS, (b) в речи агента, (c) это
зачитанный вслух URL. Фикс выше покрывает все три.

## 3. Детерминированная отправка SMS (надёжный путь)

**Вариант A — вставить в скилл в точке «после согласия / конец звонка»:**

```
{{Set(name="sms_text", value="Будь ласка, використайте це посилання для завершення реєстрації: https://clickcredit.ua/")}}
{{SendMessage(message=sms_text, actorIds=GetActors(personaId=GetUser(field="id"), integrationIdn="‹SMS_INTEGRATION_IDN›", connectorIdn="‹SMS_CONNECTOR_IDN›"))}}
```

`‹SMS_INTEGRATION_IDN›` / `‹SMS_CONNECTOR_IDN›` — из вашего списка коннекторов.
Синтаксис действия сверить с конвенциями проекта.

## 4. Агент говорит о себе в мужском роде («зрозумів» → «зрозуміла»)

**Где:** билдер → промпт **персоны агента** (Agent persona). Добавить в начало:

```
Ти — жінка. Завжди говори про себе виключно в жіночому роді,
незалежно від контексту, імені клієнта чи мови розмови.
Використовуй жіночі форми: «зрозуміла», «почула», «готова», «рада допомогти»,
«зробила», «перевірила», «надіслала», «впевнена», «вибачте, що потурбувала».
Ніколи не вживай чоловічі форми про себе («зрозумів», «готовий», «сам»).
```

Если у персоны есть атрибут пола — выставить «жіночий». Имя агента — женское.

## 5. Чек-лист проверки (после вставки)

Тестовый звонок на номер агента:
- [ ] SMS пришла ровно с текстом из §1, украинской, со ссылкой.
- [ ] На шаге отправки речь агента — украинская; URL вслух не зачитывается.
- [ ] В самореференции — «зрозуміла», а не «зрозумів».
- [ ] Язык не слетает на английский ни в тексте, ни в голосе.
